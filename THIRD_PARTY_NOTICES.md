# Third Party Notices

## LibreOffice

Release builds of Cover Letter Filler package LibreOffice inside the application bundle solely as an offline DOCX-to-PDF rendering engine. LibreOffice is not a cloud service and no Word document or placeholder value is sent outside the Mac.

The current bundled release uses LibreOffice 26.2.6 for Apple Silicon, obtained from The Document Foundation's official download infrastructure. Its downloaded disk image is verified against the publisher's SHA-256 value before it is packaged.
